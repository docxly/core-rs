docxly / WASM demo

Generate DOCX from Markdown in the browser

@docxly/core-rs is an open-source Rust core compiled to WebAssembly. This page runs the package directly in the browser and downloads the generated .docx file locally.

GitHub Source, issues, release notes npm Install the published package

Why docxly

The same Rust core powers fixture-tested DOCX generation in Node and in the browser.

What this page proves

Markdown parsing, DOCX packaging, and download all work on a static page without a backend conversion service.

Install

npm install @docxly/core-rs

Use this package in Node or a bundler-backed browser app.
